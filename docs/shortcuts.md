# Горячие клавиши BSPWM

`Super` — клавиша с логотипом Windows. Обозначения `H/J/K/L` соответствуют
направлениям влево / вниз / вверх / вправо.

## Закрепление положения окна

1. Откройте окно, расположите его на нужном мониторе и рабочем столе и сделайте активным.
2. Нажмите **Super + Shift + Z**. Окно станет плавающим; сохранятся его размер,
   координаты, монитор и рабочий стол.
3. При следующем входе распознанные приложения, включая Obsidian, откроются
   автоматически. Для прочих приложений откройте окно вручную — сохранённое
   положение применится к нему.
4. Чтобы обновить положение, передвиньте окно и нажмите **Super + Shift + Ctrl + Z**.
5. Чтобы открепить окно, выберите его и ещё раз нажмите **Super + Shift + Z**.
   Сохранение удалится, а окно вернётся в режим, который был до закрепления.
   **Super + Shift + Alt + Z** также открепляет окно.

Сохранение не фиксирует окно на месте во время текущего сеанса. Хранится одно
положение для каждого типа окна. Скрипт не запоминает отдельную вкладку браузера,
документ или команду внутри терминала. Список хранится в
`~/.local/state/bspwm/frozen-windows.tsv`.

## Приложения и утилиты

| Клавиши | Действие |
| --- | --- |
| Super + Enter | Терминал Alacritty |
| Super + D | Меню приложений Rofi |
| Super + Shift + A | Hiddify (переключает с v2rayA) |
| Super + Ctrl + A | v2rayA (переключает с Hiddify) |
| Super + Shift + F | Firefox |
| Super + Shift + N | Файловый менеджер Thunar |
| Super + Shift + P | Настройки звука Pavucontrol |
| Super + Shift + T | Telegram |
| Super + Shift + I | Приватное окно Firefox |
| Super + Shift + E | Выбор эмодзи |
| Super + Shift + C | Калькулятор; результат копируется в буфер обмена |
| Super + Shift + X | Пипетка цвета; повторное нажатие закрывает её |
| Super + Shift + K | Календарь Calcurse в терминале |
| Super + V | История буфера обмена |
| Super + W | Сменить обои |
| Super + P | Показать или скрыть Polybar |
| Super + L | Заблокировать экран |
| Super + X | Меню питания |
| Print Screen | Снимок выбранной области через Flameshot |

## Звук и экран

| Клавиши | Действие |
| --- | --- |
| Fn + F1 / Fn + F2 | Яркость вниз / вверх |
| Fn + F5 / Fn + F6 | Громкость вниз / вверх |
| Клавиши яркости ноутбука | Яркость вниз / вверх |
| Клавиши громкости ноутбука | Громкость вниз / вверх и отключение звука |
| Клавиша отключения микрофона | Включить или отключить микрофон |

## Окна и рабочие столы

| Клавиши | Действие |
| --- | --- |
| Super + 1–9 | Перейти на рабочий стол |
| Super + Shift + 1–9 | Переместить активное окно на рабочий стол |
| Super + 0 / Super + − / Super + = | Перейти на стол 10 / 11 / 12 |
| Super + Shift + 0 / Super + Shift + − / Super + Shift + = | Переместить активное окно на стол 10 / 11 / 12 |
| Super + H/J/K/L | Выбрать окно слева / снизу / сверху / справа |
| Super + Shift + H/J/K/L | Поменять активное окно с соседним |
| Alt + Tab / Alt + Shift + Tab | Следующее / предыдущее окно на текущем столе |
| Super + ` (клавиша слева от 1) | Предыдущее активное окно |
| Super + Tab | Предыдущий рабочий стол |
| Super + C | Закрыть окно |
| Super + Ctrl + Shift + C | Принудительно завершить окно |
| Super + Space | Переключить плавающий и мозаичный режимы |
| Super + T | Обычный мозаичный режим (`tiled`) |
| Super + Ctrl + T | Псевдомозаичный режим (`pseudo_tiled`) |
| Super + F | Полноэкранный режим |
| Super + Ctrl + H/J/K/L | Изменить размер окна |
| Super + Ctrl + Shift + H/J/K/L | Изменить размер с противоположной стороны |
| Super + Alt + H/J/K/L | Выбрать направление для следующего разбиения |
| Super + Ctrl + Space | Отменить выбранное направление разбиения |
| Super + Ctrl + M | Пометить окно |
| Super + Ctrl + X | Заблокировать закрытие окна средствами BSPWM |
| Super + Ctrl + Y | Показывать окно на всех столах текущего монитора |
| Super + Ctrl + Z | Сделать окно приватным для некоторых команд BSPWM |
| Super + G | Поменять окно местами с самым большим окном |

Для плавающих окон: **Super + перетаскивание левой кнопкой мыши** перемещает
окно; **Super + перетаскивание правой кнопкой** меняет его размер.

## Управление сеансом

| Клавиши | Действие |
| --- | --- |
| Super + Escape + R | Перечитать настройки горячих клавиш |
| Ctrl + Shift + R | Перезапустить BSPWM |
| Ctrl + Shift + Q | Завершить BSPWM и выйти из сеанса |

Конфигурация сочетаний: `/etc/nixos/dotfiles/sxhkd/sxhkdrc`.
Этот файл создаётся через Home Manager из `/etc/nixos/docs/shortcuts.md`.

## Физические мониторы

| Клавиши | Действие |
| --- | --- |
| Super + Ctrl + P | Настройка экранов и сохранение профиля |
| Super + [ / Super + ] | Перейти на предыдущий / следующий монитор |
| Super + Shift + [ / Super + Shift + ] | Переместить окно на другой монитор |

Подробнее: `~/nix-docs/monitors.md`. Столы 1–12 выбираются по номеру на любом мониторе. Для столов 10–12 используются клавиши 0, − и = в верхнем цифровом ряду.
