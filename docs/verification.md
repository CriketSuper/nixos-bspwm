# Проверка репозитория

Дата: 09.10.2026. Исходники взяты из работающей конфигурации Huawei MateBook D16 AMD.

Успешно выполнено:

- Проверка вычисления обоих профилей через `nix flake check --no-build`.
- Полная сборка Git-профилей `universal` и `huawei-matebook-d16`, без VirtualBox.
- Проверка ShellCheck для установщика, обновления, запуска Polybar и яркости.
- `tests/profile-portability.nix`: другой пользователь и UID 1007; корректные пути домашней папки, Xauthority и runtime-сокета Hiddify; отсутствие аппаратных исправлений Huawei в универсальном профиле; отсутствие полного NOPASSWD sudo.
- Установка из локального Git-репозитория в `/tmp/nixos-bspwm-deployment-20261009`: клонирование, генерация аппаратного конфига, сохранение существующего пользователя и stateVersion, создание рабочего локального flake. Проверена повторная установка `--replace --mode build` с сохранением `local/` и обновлением lock-файла; сборка на реальном аппаратном конфиге завершилась успешно. Активная система этой тестовой установкой не переключалась.
- Проверка Git: нет UUID исходного диска, SSH-ключей, личного WireGuard-сервера, VPN-подписок, диагностических снимков окон и RPM.

Отдельно по просьбе владельца в активной системе выполнено:

- `system.stateVersion = "26.05"` с проверкой затронутых сервисов. Службы с изменяющимися форматами данных не включены; `home.stateVersion` сохранён на `25.05`.
- Удалены VirtualBox, Super+Shift+V, группа vboxusers и загруженные модули VBox. Rebuild switch выполнен; ошибок системных служб нет.

Предыдущая полная конфигурация и RPM сохранены приватно в `~/nix-backups/git-export-current-20261009/`.
Копия до удаления VirtualBox: `~/nix-backups/virtualbox-before-removal-20261009/`.
Копия до изменения stateVersion: `~/nix-backups/state-version-before-20261009/`.
Это локальные резервные копии; их содержимое не входит в Git.

Ограничения: другой физический ПК, его GPU и док-станция ещё не проверялись. Сборочные fixtures используют тестовые разделы и не предназначены для установки напрямую.
Сам репозиторий не активирован вместо старого `/etc/nixos` на исходном ноутбуке. Пользовательские данные и настройки VPN копируются отдельно.
