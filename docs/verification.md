# Проверка репозитория

Подготовлен 09.10.2026 из актуальных исходников работающего ноутбука.
Активная система ноутбука при подготовке репозитория не переключалась.

Проверки и ограничения записываются после сборки в этом файле.
Универсальный профиль рассчитан на x86_64 и не прошёл физическую проверку на всех моделях оборудования.
Тестовые файловые системы checks в flake.nix предназначены только для сборки.
