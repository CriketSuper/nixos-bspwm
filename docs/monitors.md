# Дополнительные мониторы

## Кабели

Один монитор: подключите его к HDMI ноутбука.
Два монитора: первый через HDMI, второй через USB-C с видеовыходом (адаптер/док или прямое подключение к USB-C монитору). Кабель должен поддерживать передачу видео, а не только зарядку.
Для профиля Huawei MateBook D 16 AMD производитель указывает вывод изображения через USB-C док и HDMI:
https://consumer.huawei.com/sa-en/support/content/en-us15802827/

Наличие DP и доступные разрешения проверяются после подключения: `xrandr --query`.
Обычный HDMI-разветвитель не создаёт два независимых рабочих экрана.

## Настройка

1. Подключите мониторы, включите их и выберите соответствующий вход HDMI/DP/USB-C на самих мониторах.
2. Нажмите **Super+Ctrl+P**. Для незнакомой схемы автоматически включается расширение; для знакомой восстанавливается сохранённый профиль.
3. Выберите **Расположение и разрешение (ARandR)**. Перетащите прямоугольники согласно реальному расположению экранов. Через меню **Outputs** выберите разрешение, поворот, основной монитор.
4. Нажмите **Apply** и закройте ARandR, чтобы обновить рабочие столы и панели.
5. Снова **Super+Ctrl+P → Сохранить текущую схему**, например `home-1` или `home-2`.

Профиль хранит расположение, разрешения, частоты и включённые экраны. При повторном подключении он подбирается по мониторам. Изменение профиля не требует sudo или rebuild.
При сохранении другой схемы для того же набора мониторов предпочитайте перезапись существующего профиля: несколько профилей с одинаковым оборудованием неоднозначны для автоматического выбора.

В меню также есть **Только экран ноутбука**, **Только внешние мониторы** и ручная загрузка профиля. Режим внешних экранов не выключит экран ноутбука, если внешних мониторов нет.
Закрытие крышки здесь не настраивалось: оно по-прежнему может отправлять ноутбук в сон.

## Рабочие столы

При одном активном экране все столы 1–12 находятся на нём.
При двух: основной экран получает 1–6, второй — 7–12.
При трёх: основной получает 1–4, второй — 5–8, третий — 9–12.
Остальные экраны упорядочены по расположению слева направо.
При отключении монитора окна и столы переходят на оставшиеся экраны, приложения не закрываются. Рабочие столы перемещаются целиком, без пересоздания.

| Клавиши | Действие |
| --- | --- |
| Super+Ctrl+P | Меню мониторов |
| Super+[ / Super+] | Перейти на предыдущий / следующий физический монитор |
| Super+Shift+[ / Super+Shift+] | Переместить окно на предыдущий / следующий монитор |
| Super+1–9 | Перейти на стол с данным номером на любом мониторе |
| Super+Shift+1–9 | Переместить окно на стол с данным номером |
| Super+0 / Super+− / Super+= | Перейти на стол 10 / 11 / 12 |
| Super+Shift+0 / Super+Shift+− / Super+Shift+= | Переместить окно на стол 10 / 11 / 12 |

Polybar отображает рабочие столы своего экрана. Значки приложений в системном трее отображаются только на основном мониторе (primary); при отключении этого монитора трей переносится на оставшийся основной экран. Если панель скрыта через Super+P, подключение монитора само её не включает.
Клавиши яркости регулируют встроенную подсветку (расположение Fn зависит от ПК); яркость внешнего монитора меняется на самом мониторе.

## Простой и сон экрана

При активном внешнем мониторе отключены автоматическое гашение X11 и DPMS-сон
экранов. Это обход проблемы, при которой HDMI-монитор после сна теряет
подключение и просыпается только после переподключения кабеля.
Без активных внешних экранов возвращается прежний тайм-аут ноутбука: 10 минут.
Политика применяется при входе и после изменения схемы мониторов.

При блокировке Super+L экран по-прежнему гаснет через 5 минут, но при активном
внешнем мониторе HDMI-сигнал остаётся включённым. Сон самого ноутбука и
закрытие крышки этой настройкой не изменяются.

Проверка: `xset q` — при внешнем экране должны быть `timeout: 0` и
`DPMS is Disabled`. Если монитор снова исчезнет даже с отключённым DPMS,
проверьте `xrandr --query`: `disconnected` означает потерю обнаружения монитора,
а `connected` без разрешения — выключенный видеовыход.

## Проверка и восстановление

Список экранов: `xrandr --query`.
Список профилей: `autorandr --list`.
Применить профиль: `autorandr --load home-1`.
Сохранить вручную: `autorandr --save home-1` (для перезаписи добавьте `--force`).
Если требуется восстановить встроенный экран из терминала ноутбука:

```sh
xrandr --output eDP-1 --auto --primary --pos 0x0
python3 ~/.config/scripts/sync-monitors.py
```

Ручное применение произвольного скрипта ARandR также стоит завершить вызовом `python3 ~/.config/scripts/sync-monitors.py`.
Исходники: `/etc/nixos/services/displays.nix`, `/etc/nixos/dotfiles/scripts/sync-monitors.py`.
Профили: `~/.config/autorandr/`. Графические профили ARandR в `~/.screenlayout/` сами по себе не становятся автопрофилями: их нужно применить и сохранить через меню мониторов.
