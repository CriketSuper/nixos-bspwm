# OpenVPN через NetworkManager

OpenVPN и графический плагин включены в конфигурации NixOS.

1. Получите `.ovpn` у своего VPN-провайдера.
2. Запустите `nm-connection-editor` из терминала или редактор сетевых подключений из меню.
3. Нажмите `+`, выберите «Импортировать сохранённую конфигурацию VPN» и укажите `.ovpn`.
4. Если провайдер требует логин/пароль, заполните их в настройках VPN. Для отдельных файлов сертификатов/ключей укажите существующие пути.
5. Сохраните профиль. Включайте его через меню значка сети → VPN-подключения.

Через терминал:

```sh
nmcli connection import type openvpn file "$HOME/Downloads/provider.ovpn"
nmcli --ask connection up id "ИМЯ ИМПОРТИРОВАННОГО ПРОФИЛЯ"
nmcli connection down id "ИМЯ ИМПОРТИРОВАННОГО ПРОФИЛЯ"
```

Импорт не включает VPN автоматически. Имя смотрите в выводе импорта или `nmcli connection show`.
Перед подключением отключите Hiddify/v2rayA/Amnezia: несколько VPN одновременно могут конфликтовать маршрутами и DNS.
Профили, пароли и закрытые ключи храните вне репозитория конфигурации.
Подключение к вашему серверу пока не проверено: для этого нужен ваш `.ovpn`.
