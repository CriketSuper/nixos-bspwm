# Как менять TLS fingerprint в v2rayA и Hiddify

Fingerprint здесь — профиль TLS ClientHello, например `chrome` или `firefox`.
Он не меняет установленный браузер и не является паролем или ключом сервера.
После импорта своего узла можно изменить его fingerprint; готовые подписки в репозитории отсутствуют.

## v2rayA: изменить уже созданную копию

1. Откройте **Super + Ctrl + A** или <http://127.0.0.1:2017>.
2. Нажмите **Stop / Остановить** для отключения VPN на время изменения.
3. Перейдите на вкладку **SERVER** и найдите импортированную копию узла.
4. Нажмите **Modify / Изменить** рядом с узлом.
5. Во вкладке **V2RAY** найдите **uTLS fingerprint**, под полем SNI.
6. Выберите нужное значение — например, `firefox` или `chrome`.
7. Нажмите **Save and Apply / Сохранить и применить**.
8. Выберите этот узел кнопкой **Connect / Подключить**, если он ещё не выбран,
   и нажмите **Start / Запустить** сверху. Проверьте открытие сайта.

В установленной версии 2.2.7.5 форма содержит `chrome`, `firefox`, `safari`,
`ios`, `android`, `edge`, `random`, `randomized`. Поддержка конкретного варианта
зависит от ядра и конфигурации соединения. Для возврата используйте значение из исходной ссылки своего провайдера.

### Если узел находится внутри подписки

Вкладка подписки позволяет только **View / Просмотреть**; там нельзя сохранить изменения.

1. Рядом с нужным узлом нажмите **Share / Поделиться** и скопируйте его `vless://`-ссылку.
2. В текстовом редакторе измените только параметр fingerprint:

   ```text
   fp=chrome → fp=firefox
   ```

   Если `fp` отсутствует, добавьте `&fp=firefox` к параметрам после `?`, перед `#`.
   Если это первый параметр, используйте `?fp=firefox`.
3. После `#` можно указать другое имя, например `My-node%20Firefox`.
4. Нажмите **Import / Импортировать** в v2rayA и вставьте изменённую ссылку.
5. Копия появится на вкладке **SERVER**. Выберите её и запустите VPN.

Ссылка содержит секрет доступа к VPN; храните её у себя. UUID, адрес, порт,
SNI, `pbk`, `sid`, `flow` при смене fingerprint оставляйте такими, какими их выдал сервер.

## Hiddify 4.1.1

В этой версии отдельного общего переключателя uTLS fingerprint в настройках нет.
Значение берётся из самого узла. Укажите fingerprint в импортируемой ссылке.

Чтобы изменить его самостоятельно:

1. Возьмите `vless://`-ссылку узла. Например, в v2rayA нажмите **Share** возле нужного узла на вкладке **SERVER** и скопируйте ссылку.
2. В редакторе измените `fp=firefox` на нужное значение, например `fp=chrome`.
   Для сохранения прежнего варианта дайте новой копии отличающееся имя после `#`.
3. Скопируйте всю изменённую ссылку в буфер обмена.
4. Откройте **Super + Shift + A**. Нажмите **+ → Буфер обмена**.
5. Выберите новый профиль в верхнем списке на главной странице.
6. В режиме **VPN** нажмите большую кнопку подключения.

Другой поддерживаемый формат — Sing-box JSON. Там значение находится в исходящем
VLESS-узле, в `tls.utls`:

```json
"utls": {
  "enabled": true,
  "fingerprint": "firefox"
}
```

Этот фрагмент показывает поле; его не нужно импортировать как отдельный полный профиль.

## Подписка и обновления

Копии с изменённым fingerprint — самостоятельные локальные узлы/профили.
Они не получают новые адреса и ключи при обновлении исходной подписки. Если провайдер
изменит параметры, экспортируйте свежий узел и повторите создание копии.
Для автоматического применения ко всем узлам настройте преобразование подписки
или запросите нужные параметры у провайдера.

Ярлыки Hiddify и v2rayA переключают службы между собой. При работе с другим клиентом
предыдущее VPN-подключение выключается. Закрытие вкладки панели v2rayA VPN не отключает.
